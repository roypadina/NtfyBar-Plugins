# Changelog

All notable changes to this marketplace are listed here. Each plugin's own version is in its
`plugin.json`.

## [Unreleased]

## [1.1.0] - 2026-10-23

### Added
- `com.ntfybar.alert-card` 1.0.0, `com.ntfybar.history-conditions` 1.0.0 (Repeat & Burst), `com.ntfybar.extract` 1.0.0 — also bundled with NtfyBar 1.1.0.
- `com.ntfybar.time-window` 1.0.0 and `com.ntfybar.reply-buttons` 1.0.0 — marketplace examples.
- `com.ntfybar.json-fields` 1.1.0: "JSON field changed" condition.
- Docs: popup `position`/`level`, `choice` params, `ntfy.publish` `delay` (NtfyBar 1.1+).

## [1.0.0] - 2026-10-23

### Added
- Marketplace index `marketplace.json` with per-file SHA-256 checksums.
- `com.ntfybar.ack-button` 1.0.0 — popup with an ACK button that replies on the same topic.
- `com.ntfybar.json-fields` 1.0.0 — JSON field condition and a table popup with the previous value.
- `scripts/validate.py` and CI.
- Docs: authoring, permissions, popup spec, publishing.
